# What's New With 2.11.x

## \[2.11.1] - 2026-08-04

### Fixed

* Date formatting issue for BoxLang Prime support.

## \[2.11.0] - 2026-06-24

### Added

* BoxLang Prime support.
* New native `BXMail` protocol that sends mail via `bx:mail`. See the [BXMail protocol](../../protocols/bxmail.md).
* ColdBox 8 support.
* More BoxLang tests.

### Changed

* Removed automated tests for old engines.
